zigos を RISC-V エミュレータで動かす

- 停止中 0.0 MIPS
wasm とカーネルを読み込み中…

  

    

      

        
試してみよう

        
    
          
  • Go で書いた RISC-V エミュレータ (emu/) を wasm にして、Zig で書いた小さな OS (os/) をブラウザの中で起動しています。ターミナルをクリックして ls, cat /etc/motd, ps, uptime, run counter & と打ってみましょう。
    • 
          
  • 「一時停止」→「次のトラップまで」を押すと、シェルが ecall でカーネルを呼んだ瞬間 (U→M) や、カーネルが mret でシェルに戻る瞬間 (M→U) で止まります。右上の特権モードバッジと mcause / mepc の変化を見てください。
    • 
          
  • 「1 ステップ」で 1 命令ずつ進めると、トラップベクタ (trap_vector) がレジスタを保存していく様子がわかります。ecall の a7 はシステムコール番号 (トラップログに名前を表示)。
    • 
          
  • 入力待ちのあいだカーネルは M モードで wfi して待っており、タイマは割り込みとしてではなくループの中で処理されるのでトラップは起きません。キーを押すとシェルが起き上がります。
    • 
          
  • mtime は 1 命令ごとに 1 増えます (10 MHz 相当)。待ち (wfi) の間だけ実時間に合わせて進めるので、uptime はだいたい実時間になります。
