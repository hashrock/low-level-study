見どころ

  1. 3-way handshake: 「TCP echo」を押すと [SYN] → [SYN,ACK] → [ACK] が往復し、両側が ESTABLISHED になる。最初の通信の前には ARP の who-has / is-at が飛ぶ (「ARP キャッシュ消去」でもう一度見られる)。
  2. 再送: 損失を 20% にして「TCP bulk」。✕ で落ちたセグメントのあと、受信側は同じ ack を繰り返し (dup ACK)、3 回目で送信側が fast retx。ACK も来なければ RTO 切れで未 ACK の先頭から送り直す (Go-Back-N)。↻ が再送。最後に SHA-256 で一致を確認する。
  3. TIME_WAIT: echo のあと先に FIN を送ったクライアント B は FIN_WAIT_1 → FIN_WAIT_2 → TIME_WAIT と進み、2 秒 (本来は 2MSL) 待ってから CLOSED。サーバ A は CLOSE_WAIT → LAST_ACK → CLOSED。
  4. 1 コマずつ: 「ケーブル一時停止」→ ping → 「1 フレーム届ける」で 1 枚ずつ配送。「先頭を捨てる」で ARP や SYN を落とし、再送の様子を見る。
  5. RST: 誰も LISTEN していない :81 へ SYN を送ると [RST,ACK] が返り、接続は即座に失敗する。

pcap は Wireshark でそのまま開けます (時刻はケーブルに乗った時刻)。TCP の seq/ack は ISN を 0 とする相対値で表示しています。
