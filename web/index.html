Low-level Playground

自作の CPU・OS・アセンブラ・コンパイラ・言語・DB・TCP/IP・JS ランタイムを、ブラウザ上で動かして中身を覗く。すべて Go（OS は Zig）→ WebAssembly。

OS on 自作 CPU emu + os

Zig 製ミニ OS を RISC-V エミュレータで起動。シェルを触りながら CPU を一時停止して覗く。

  • レジスタ・CSR・特権モード (U/M)
  • 逆アセンブル・1 命令ステップ
  • トラップ／システムコールのログ・メモリダンプ

CPU を 1 クロックずつ hw (Verilog)

Verilog で書いた RISC-V CPU を本物のシミュレーション波形で再生。命令が回路のどの線を流れるかを見る。

  • データパス図・使われる線のハイライト
  • パイプライン図 (バブル・フォワーディング・フラッシュ)
  • ミニ波形ビューア

論理ゲート transistor → gate → adder

CMOS トランジスタから NAND、加算器、デコーダ、フリップフロップまで。ビットが伝わる様子をアニメーションで。

  • 桁上がりの伝搬とクリティカルパス
  • opcode デコーダ (decoder.v と対応)
  • クロックの立ち上がりで値を取り込む

コンパイル → 実行 cc / compiler → asm → emu

C や minilang のソースが、アセンブリ → 機械語のビット → ELF → CPU 実行になるまでを一画面で。

  • ソース行 ↔ アセンブリ ↔ 機械語の対応
  • 命令形式 (R/I/S/B/U/J) のビット分解
  • -O0 / -O2、静的型 vs 動的型の命令数比較

バイトコード VM lang

JS 風言語のバイトコードを 1 命令ずつ実行。スタック・フレーム・クロージャの箱が動く様子を見る。

  • ソース ↔ バイトコードの対応
  • 値スタック・コールスタック・グローバル
  • クロージャが共有する箱

B+tree RDB db

SQL を打つたびに B+tree が育ち、ページが分割される。4KB ページを 16 進で覗く。

  • B+tree の図・分割のハイライト
  • ページのバイト配置
  • インデックス検索 vs 全件走査

TCP/IP スタック net

ページ内の 2 ノードが通信。パケットをシーケンス図で追い、ロス率を上げて再送を観察。

  • 3-way handshake・FIN・TIME_WAIT
  • パケットの層ごとの分解・hex
  • pcap ダウンロード

JS ランタイム runtime

自前イベントループの中身を可視化。microtask と timer の順番、パーミッションの判定を見る。

  • コールスタック・microtask・timer ヒープ
  • 実行順クイズ
  • パーミッションログ (../ の正規化)
